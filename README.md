# SehatSathi — Smart Health & Diet Companion

SehatSathi is a mobile-first health and diet companion app built for Bangladeshi users.

## Features
- Firebase Auth (email/password)
- Firestore cloud sync across devices
- AI Medicine Info (Claude Haiku)
- AI Diet Plan — personalised Bangladeshi meal plan
- Reminders with browser notifications
- BMI Calculator
- Offline localStorage fallback

## Setup
```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and fill in your Firebase + Claude API keys.

## Tech Stack
Next.js 16 · React 19 · Tailwind CSS v4 · Firebase · Claude Haiku · TypeScript
